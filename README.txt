AJITH P - PORTFOLIO
===================

Files:
- index.html
- style.css
- script.js

To run:
1. Keep all files in the same folder.
2. Open index.html in any modern browser.
3. Optional: place your resume PDF in this folder and name it exactly resume.pdf.

Notes:
- Replace the profile placeholder in index.html with your own photo later if desired.
- Contact form opens the visitor's default email client; it does not require a backend.
